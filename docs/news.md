Путь материала: сбор → нормализация → дедупликация → разбор моделью. Аналитика Альфа-Банка идёт отдельным входом и встречается с новостями в общей ленте.

## Сбор

Задача A3-01, модуль `app/news/fetch.py`, список источников — [`backend/app/news/sources.yaml`](../backend/app/news/sources.yaml) (путь задаёт `NEWS_SOURCES_FILE`, относительный — от каталога `backend`).

Рекомендованного списка источников у кейса нет: подходят любые законные бесплатные способы. Берём открытые RSS деловых СМИ и регуляторов.

| Источник | Тип | Текст |
| --- | --- | --- |
| Интерфакс, ПРАЙМ, Коммерсантъ — Экономика, Ведомости — Бизнес, Экономика, Финансы | `media` | в ленте только анонс, качаем страницу статьи |
| Российская газета, Forbes | `media` | полный текст есть в ленте |
| Банк России — пресс-релизы и события, Минпромторг | `regulator` | официальная позиция; у событий ЦБ качаем страницу |
| РИА Новости, Коммерсантъ — Все новости | `media`, резерв | обходятся, только пока недоступны основные (`backup_for`) |
| ТАСС, РБК | `media`, выключены | не отвечают из нашей сети, оставлены для стенда |

### Как обходим

- **Расписание.** У каждого источника свой интервал (`interval_minutes`, по умолчанию `NEWS_FETCH_INTERVAL_MINUTES`). Состояние хранится в таблице `news_sources_state`: когда обходили, когда был успех, сколько ошибок подряд, когда обходить в следующий раз.
- **Ошибки.** Если источник не ответил, следующая попытка будет через 5, 10, 20 минут и так далее, но не реже раза в шесть часов. После трёх ошибок подряд источник считается недоступным, и включаются его резервные.
- **Повторы.** Временные ошибки (таймаут, обрыв, 429, 5xx) повторяются дважды с паузой 1 и 2 секунды. Если сервер прислал `Retry-After`, ждём сколько он просит, но не больше минуты. На 4xx не повторяем.
- **Вежливость.** Между запросами к одному сайту — не меньше секунды. Свой `User-Agent` (`NEWS_USER_AGENT`). robots.txt соблюдаем по правилам Google: группа самого точного User-agent, шаблоны `*` и `$`, побеждает самое длинное правило. Стандартный `urllib.robotparser` для этого не годится: он не понимает `*` и правило `Disallow: /?` (оно есть у Коммерсанта) читает как запрет всего сайта. Нет robots.txt — можно обходить, сайт не ответил — не обходим.
- **Без лишних запросов.** Ссылка приводится к одному виду (без `utm_*`, якоря, хост в нижнем регистре). Страницы статей, которые уже сохранены, повторно не качаются.

### Что сохраняем

Таблица `raw_news` — материал как его отдал источник, без обработки: так нормализацию (A3-02) можно пересчитать, не обходя источники заново.

| Поле | Что это |
| --- | --- |
| `raw_id` | `raw:` + хеш ссылки |
| `source_id`, `url`, `guid` | источник, ссылка на первоисточник, id записи в ленте |
| `title`, `summary`, `feed_text` | заголовок, анонс и полный текст, если лента его отдаёт |
| `html` | страница статьи, если источник отдаёт только анонс |
| `published_at`, `fetched_at` | время публикации по ленте и время сбора, UTC |
| `article_status` | `feed_only` — текст из ленты, `fetched` — страница скачана, `robots` — robots.txt запрещает, `failed` — страница не ответила, `too_large` — больше 3 МБ |

### Запуск

```
cd backend
uv run python -m app.news                       # один обход: все источники, которым пора
uv run python -m app.news --source interfax     # один источник вне расписания
uv run python -m app.news --loop                # обходить по расписанию, не выходя
```

Команда печатает отчёт: сколько новых материалов у каждого источника и какие ошибки. Первый обход 21.10.2026 собрал 279 материалов из 11 источников.
