# Работа с LLM

## Разрешённые модели

Кейс разрешает только эти шесть. Использование любых других моделей, а также внешних AI-сервисов, автономных AI-агентов и готовых мультиагентных систем как основного компонента решения не допускается.

| Модель | Для чего предложена в кейсе |
| --- | --- |
| Gemma 4 26B A4B | простые задачи: классификация, извлечение информации, преобразования текста |
| GLM-5.3-Flash | задачи повышенной сложности, рассуждения |
| Qwen3.6 35B A3B | универсальная: анализ текста, генерация, обработка материалов |
| DeepSeek-V4.1-Flash | исследовательские задачи, поиск взаимосвязей, большие объёмы |
| Qwen3-VL-30B-A3B-Instruct | изображения и мультимодальные данные |
| Kimi-K2.6 | обработка и анализ текстовой информации |

Как раскладываем по шагам: извлечение сущностей и классификация новостей — быстрая модель; переранжирование кандидатов и сборка вывода — сильная; разбор картинок не используем, пока не появится задача.

## Ключ и бюджет

Ключ общий на команду, дневной лимит — 500 ₽ на всю команду. Отсюда правила:

- Ключ живёт только в `.env` и в секретах стенда. В репозиторий, скриншоты и презентацию он не попадает.
- Все вызовы идут через один клиент в `app/core`: там лимиты, таймауты, ретраи с backoff и учёт стоимости.
- Каждый вызов пишет в лог модель, число токенов и стоимость; суточный расход считается по этим записям.
- При приближении к лимиту сервис деградирует предсказуемо: сначала отключается переранжирование, потом сборка выводов, но лента и профиль продолжают работать.
- Ответы LLM кэшируем по хешу запроса: повторный прогон демо не должен стоить второй раз.
- Нагрузочные эксперименты гоняем на сохранённых ответах, а не на живом ключе.

## Промпты

- Промпты лежат в коде рядом с модулем, который их использует, и версионируются вместе с ним.
- В промпт не уходит ничего, кроме нужных для шага данных.
- Текст новости и любой внешний контент подаются как данные, а не как инструкции: инструкции модели отделены от контента маркерами, а ответ разбирается по схеме. Это защита от prompt injection через новостной источник.
- Любой ответ модели валидируется по Pydantic-схеме; невалидный ответ — это ошибка шага, а не повод показать пользователю сырой текст.
