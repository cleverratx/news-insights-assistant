# 0002. Отбор новостей без эмбеддингов

Статус: принято, 19.10.2026; пересмотреть, если организаторы подтвердят доступную эмбеддинг-модель

## Контекст

Для отбора новостей под компанию напрашивается векторный поиск. Но кейс разрешает ровно шесть генеративных моделей, и эмбеддинг-модели среди них не названы. Поднимать свою модель эмбеддингов — риск получить замечание на проверке; гонять все новости через LLM — риск выйти за дневной лимит.

## Решение

Двухступенчатый отбор:

1. **Лексический.** BM25 по тексту новости против расширенного запроса из профиля компании: формулировка ОКВЭД, отрасль, регионы, продукты банка, контрагенты, отраслевые термины.
2. **Переранжирование.** Верхние кандидаты уходят в разрешённую LLM, которая оценивает связь с бизнесом и значимость.

Вопрос про эмбеддинги задан организаторам (строка в листе «Вопросы организаторам» роадмапа). Если доступная модель появится, слой отбора заменяется за один PR: интерфейс `app/rank` остаётся прежним.

## Последствия

- Отбор дешёвый и предсказуемый по стоимости: LLM видит десятки кандидатов, а не всю ленту.
- Хуже ловятся переформулировки, поэтому запрос из профиля расширяем синонимами и отраслевыми терминами.
- Качество отбора измеряем на размеченной вручную выборке, не на ощущениях.
