# Поиск по аналитике банка и новостям

Задача A3-07, модули `app/search/engine.py`, `app/search/rerank.py`, `app/search/service.py`, схема ответа — [schemas/search_result.schema.json](schemas/search_result.schema.json). Это инструмент для агента и интерфейса: найти, что банк и пресса пишут по вопросу, и показать это дословной цитатой со ссылкой. RAG разрешён кейсом, если связь выводов с источниками сохраняется, а эмбеддингов у нас нет ([ADR 0002](decisions/0002-otbor-bez-embeddingov.md)). Поэтому поиск двухступенчатый.

## Как ищем

1. **BM25 по фрагментам.** Единица поиска — фрагмент, а не документ: абзац новости или абзац аналитики «стр. N, абзац M». Так цитата точная, а ссылка ведёт к месту. К тексту фрагмента для поиска добавляется заголовок материала. Слова приводятся к основе из первых пяти букв, числа берутся целиком, служебные слова отбрасываются. Оценка BM25 (`rank-bm25`, Okapi) умножается на долю слов запроса во фрагменте: подпись графика, где десять раз повторено «цены», не обгонит абзац, где есть и «цены», и «золото».
2. **Переранжирование моделью.** До 12 лучших кандидатов уходят сильной модели (`Task.RERANK` → `LLM_MODEL_SMART`). Она возвращает строгий JSON — оценку от 0 до 1 и дословную цитату для каждого фрагмента. Фрагменты передаются между маркерами `<<<ФРАГМЕНТЫ … ФРАГМЕНТЫ>>>`, и команды внутри них не исполняются. Итоговая оценка складывается из оценки модели (0,8) и нормированного BM25 (0,2). Фрагменты с оценкой модели ниже 0,2 отбрасываются.

## Цитата и ссылка — всегда

У каждой находки (`SearchHit`) есть:

- `quote` — дословная цитата. Если цитату дала модель, она проверяется: её текст должен найтись во фрагменте (сравнение без учёта регистра и пробелов). Выдуманная цитата заменяется предложением фрагмента, где больше всего слов запроса;
- `document` — где искать, с датой материала: «название (11.09.2026), стр. N, абзац M» для аналитики банка, «издание: заголовок (дата), абзац N» для новости. Дата нужна, чтобы старый прогноз не выглядел текущей позицией банка: среди материалов кейса есть обзор российской стали от апреля 2021 года;
- `doc_id`, `fragment_id`, `locator` — для перехода к месту в интерфейсе;
- `url` — первоисточник новости;
- `kind` — `bank_analytics` или `news`: видно, где позиция банка, а где пресса.

## Откуда материалы

Аналитика банка берётся из `analytics_documents` (A3-06), новости — из `news_items` за последние 14 дней (A3-02). Если таблицы ещё нет или запись не проходит схему `NewsItem`, поиск идёт по тому, что есть, а в `warnings` написано, чего не хватило. Индекс строится на каждый запрос: материалов сотни, это быстрее и проще кеша.

Агент ищет позицию банка отдельно, `kinds=[bank_analytics]` — это ответ на вопрос «как это оценивает банк».

## Без модели

Если ключа нет, бюджет исчерпан или ответ модели не прошёл проверку, остаётся порядок BM25. Оценка тогда — доля от лучшего результата, `reranked=false`, причина — в `warnings`. Поиск при этом работает.

```
cd backend
uv run python -m app.search "сохранит ли ЦБ ключевую ставку до конца года"
uv run python -m app.search "прогноз роста ВВП" --bank -n 3
uv run python -m app.search "экспорт угля" --news --no-rerank
```
