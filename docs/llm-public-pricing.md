значения из кешированных версий; для этого снимка использован ответ API.

## Применимость к проекту

В проекте используется шлюз `changellenge.up.railway.app`, а приведённые ставки
опубликованы OpenRouter. Совпадение ID моделей не подтверждает одинаковые тарифы:
неизвестны выбранный upstream, наценка и курс пересчёта шлюза в рубли.

Публичные ставки подходят для предварительной оценки затрат. Для оценки в рублях
нужно явно задать курс USD/RUB; такой результат следует обозначать как оценку,
не выдавая за подтверждённое списание шлюза. Клиент поддерживает режим
`LLM_PRICING_MODE=public_estimate`: снимок цен встроен в `app/llm/pricing.py`.
`LLM_ESTIMATE_USD_RUB=100` задаёт расчётный курс, а
`LLM_ESTIMATE_SAFETY_MULTIPLIER=2` — запас при расчёте и резервировании.
Это параметры оценки, не подтверждённый курс или наценка организаторов.
В результате и логах сохраняются режим, источник, дата снимка, курс и коэффициент.
Лимит 500 ₽ и сброс в 03:00 МСК на стороне организаторов подтверждены их инструкцией.

Для подтверждения фактических списаний нужен опубликованный тариф шлюза либо
доступный через него учёт расходов. Дополнительные запросы генерации для выяснения
цен в рамках этой проверки не выполнялись. Ключ команды не передавался OpenRouter:
каталог тарифов получен без авторизации.
