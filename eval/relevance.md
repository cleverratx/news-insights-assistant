**Что это значит:**

- В первых пяти карточках ленты в среднем треть материалов касается компании (5 из 15). У обычной ленты «свежие сверху» — 1 из 15.

**Насколько этому верить.** Выборка маленькая: 15 мест в первых пятёрках. 95% доверительный интервал Уилсона для 5 из 15 — от 15% до 58%, для 1 из 15 — от 1% до 30%. Интервалы пересекаются, поэтому превосходство над обычной лентой на этом объёме статистически не доказано, есть только направление. Каждая карточка — это 20 п. п. P@5 одной компании.

## Методика

1. **Снимок** (`eval/relevance/snapshot.json`). Профили компаний, материалы и момент времени замораживаются. Метрика пересчитывается без базы и сети, а балл свежести не плывёт. Текстов источников в снимке нет: у новостей лид до 300 знаков, заголовок, ссылка и разбор, у аналитики банка — только заголовок и разбор. От фактов остаются статус и цифры.
2. **Набор для разметки** (pooling). По каждой компании в лист попадают:
   - первые 10 карточек ленты;
   - первые 5 карточек обычной ленты;
   - 8 случайных материалов из окна (фиксированное зерно).

   Итого 68 пар. Случайные материалы нужны, чтобы видеть пропуски: релевантное, которое лента не подняла.
3. **Разметка вслепую** (`eval/relevance/labels.csv`). Пары перемешаны, баллов, мест и причин отбора в листе нет. Разметчик видит карточку компании (признаки профиля) и материал: заголовок, лид, издание, дату. У каждой оценки — письменное обоснование.
4. **Метрика.** P@5 — доля релевантных (оценка ≥ 1) среди первых пяти карточек. Если лента короче пяти, пустые места считаются промахом. «Только „прямо“» — то же для оценки 2. «Потолок» — лучший P@5, возможный на этом наборе. Обычная лента — одна публикация на сюжет, свежие сверху, одинаковая для всех: так выглядит лента без персонализации.

## Критерии разметки

Зафиксированы до просмотра пар.

| Оценка | Когда ставим | Пример из разметки |
| --- | --- | --- |
| **2 — прямо** | событие меняет выручку, затраты, долг, поставки, сбыт или регулирование компании через её конкретный признак: её рынок, отрасль крупного покупателя или поставщика, страны ВЭД и валюту расчётов, стоимость долга при заметной долговой нагрузке, правила её отрасли, конкурентов, деловое событие в её регионе | прогноз «ЦБ не снизит ставку до 2027 года» для оптовика с кредитами и лизингом |
| **1 — косвенно** | общий экономический фон, который касается и её (инфляция, платёжный баланс, промышленная политика), или смежный рынок с небольшой долей. Полезно знать, действий не требует | подорожание бизнес-ланчей для поставщика ресторанов: рынок покупателей, но это статистика, а не событие |
| **0 — не касается** | связи с бизнесом компании нет: чужие отрасли и регионы, меры для граждан, политика и происшествия без экономического следствия | снятие санкций с гендиректора «Беларуськалия» для оптовика продуктов |

## Разбор ошибок

В первых пятёрках 10 нерелевантных карточек. Причины:

| Причина | Сколько | Примеры |
| --- | --- | --- |
| Словарный разбор приписал новости чужой рынок | 7 | «Папе Льву XIV не потребуется лечение» → здравоохранение (слово «лечение»); «США сняли санкции с гендиректора „Беларуськалия“» → продукты питания; «снятие санкций с NIS» и «скидки на нефть для Китая» → транспорт и логистика; «измельчители древесины в реестре Минпромторга» → здравоохранение; «ФРП Астраханской области выдал займы» → продукты питания и долговой рынок |
| Рынок угадан верно, но события для бизнеса нет | 2 | «Студенческий чемпионат по кибербезопасности» и «банки будут отклонять переводы с заражённых смартфонов» у IT-компании, которая работает с финансовым сектором |
| Слишком широкое правило продуктов | 1 | законопроект о непубличных кредитных рейтингах поднят у производителя медтехники через гарантии и депозиты |

Словарь навешивает новости по 2–4 сегмента по любому совпавшему слову, а правила отбора доверяют разбору. Без модели это главный источник мусора. Модель на шаге проверки кандидатов (A4-03) должна отсекать как раз такие случаи, но это нужно подтвердить замером.

Пропуски: лента не подняла в первую десятку 4 релевантных материала, все с оценкой 1 — платёжный баланс, расчёты в нацвалютах со странами ШОС, обзор долгового рынка от Альфа-Банка, промышленная политика. Ни одна новость с оценкой 2 не потеряна.

## Что делать дальше

Порядок — по ожидаемому эффекту. Каждое изменение перемеряется на этой же разметке. Разметку под изменения не правим, иначе метрика начнёт подгоняться под систему. Новые пары, которые попадут в пятёрку, размечаются по тем же критериям.

1. **Перемер с моделью.** Собрать снимок с ключом LLM: новости разберёт модель (A3-04), а лента пройдёт проверку кандидатов (A4-03). Это рабочий режим, и именно его стоит показывать.
2. **Строже запасной словарь.** Сегмент — только если слово есть в заголовке или встречается в тексте несколько раз; не больше двух сегментов на новость.
3. **Порог значимости.** Не показывать новости, где совпала только отрасль, но нет ни одного делового маркера (событие, цифры, решение).
4. **Правило продуктов.** Тема «долговой рынок» без ставки не должна поднимать гарантии и депозиты.
5. **Расширить эталон.** Добавить реальные демо-компании, когда будут выгрузки, и второго разметчика-человека, чтобы посчитать согласие разметчиков.

## Как повторить

```
cd backend
uv run python scripts/eval_relevance.py score            # пересчитать по снимку и разметке
uv run python scripts/eval_relevance.py score --write    # и обновить таблицу «Итог» в этом файле
```

Новый снимок (нужна база с загруженными данными и новостями; с ключом LLM — замер рабочего режима):

```
uv run python -m app.data --samples
uv run python -m app.analytics
uv run python -m app.news run
uv run python scripts/eval_relevance.py freeze           # профили и материалы → snapshot.json
uv run python scripts/eval_relevance.py pool             # лист разметки → labels.csv (перезапишет!)
```

Команда `pool` перезаписывает `labels.csv`, поэтому старую разметку переносят по паре «компания — материал». Если в первой пятёрке окажется неразмеченная пара, `score` назовёт её и посчитает промахом.

## Для презентации

> Персональная лента без модели: в первых пяти карточках 33% материалов касаются компании, у обычной новостной ленты — 7%. Ленты трёх компаний почти не пересекаются (7%). Главный источник ошибок — запасной словарный разбор; в рабочем режиме его заменяет модель. Эталон — 68 размеченных пар «компания — материал», замер воспроизводится одной командой.

Пока нет перемера с моделью и проверки разметки человеком, формулировку «работает хорошо» не используем.
