# Состояния ответа ИИ (A6-09)

`AnalysisProgress` показывает подготовку разбора в стиле существующего интерфейса:
карточка, короткое объяснение, состав обработки и время ожидания. Компактный вариант
используется в уточняющем диалоге. После минуты текст объясняет, что ответ требует
больше времени; отсчёт продолжается, действия остаются доступны. Проценты готовности
и обещание закончить за определённое время не показываются.

Текущий `POST /companies/{company_id}/insights` возвращает готовый JSON. Он не передаёт
текущий этап и не поддерживает потоковую выдачу текста. Поэтому список «Что входит
в разбор» описывает обработку целиком; шаги не получают отметки о завершении по
таймеру. Для настоящего отображения текущего этапа потребуется отдельный контракт
событий сервера. Побуквенная имитация стриминга не используется.

«Остановить ожидание» прерывает клиентский запрос и показывает возможность
запросить ответ снова. Это не гарантирует остановку обработки на сервере.
Запоздавший ответ отменённого запроса не заменяет экран отмены. Повтор создаёт
новый индикатор с нулевым временем.

`EmptyState` и `ErrorState` используют одинаковую типографику и кнопки UI-kit.
На экране разбора различаются пустой ответ, отсутствие заметного влияния,
нехватка данных и техническая ошибка. Частичный ответ сохраняет доступный текст;
пробелы раскрываются по ссылке «Чего не хватило», при сбое обработки можно повторить
разбор. Полностью пустой ответ не создаёт ряд пустых карточек разделов.

Индикатор доступен скринридеру через `role="status"`; таймер не объявляется каждую
секунду. Анимация отключается при `prefers-reduced-motion`. Основной текст — 16 px,
подписи — 14 px; элементы переносятся на узких экранах.

## Проверка

```bash
npm run lint -- --max-warnings=0
npm run typecheck
npm test
npm run build
```

`tests/insight-states.test.mjs` проверяет границы пустого и частичного результата,
отсутствующие утверждения и приоритет статусов без обращения к LLM.

В браузере с подменой API: задержать ответ, проверить ожидание после минуты,
отменить и повторить запрос; вернуть ошибку 503, пустой результат, `timeout`,
`insufficient_data`, `no_significant_link` и полный ответ. Проверить уточняющий
вопрос, ширины 1440/390 px и режим уменьшения движения.
