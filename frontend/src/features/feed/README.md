# Фильтры ленты

A6-07, критерий 10. На `/feed` доступны тип события, период 1/3/7/14 дней,
значимость (высокая, средняя, низкая) и режимы «Все», «Только риски», «Возможности».
Фильтры работают совместно; сводка влияния строится по показанным карточкам.

Тип события соответствует маркерам из `shared/lib/markers.ts`. Тип, период и
значимость передаются в API перед ограничением выдачи. При выборе значимости
`min_importance=0` позволяет увидеть и низкую значимость, обычно скрытую порогом.
Высокая значимость объединяет уровни «Критично» и «Важно», средняя соответствует
«К сведению», низкая — «Фон». Контракт ответов и ранжирование не меняются.

Период ограничивает новости. Аналитика банка участвует независимо от даты
публикации, как предусмотрено существующим контрактом API.

Риски и возможности определяются по `event.polarity` для выбранной компании,
а не по общему тону новости. Переключение режима выполняется локально и не
вызывает модель. API ограничивает выдачу 50 карточками; режим влияния применяется
к этой ленте, а счётчики не выдаются за размер всей базы.

Параметры хранятся в URL: `marker`, `days`, `significance`, `polarity`, `all`.
Старая ссылка `important=1` открывает высокую значимость. Обновление страницы,
навигация назад/вперёд и возврат из разбора сохраняют настройки. Сброс возвращает
период 7 дней, убирает все фильтры и показ фона, сохраняя компанию, должность и вкладку.

При смене запроса старые карточки и сводка не показываются под новыми фильтрами.
Ошибку можно повторить; выбранные настройки сохраняются. Для пустого результата
доступен сброс, а варианты фильтров остаются доступны даже без совпадений.

## Проверка

```bash
cd frontend
npm test
npm run lint -- --max-warnings=0
npm run typecheck
npm run build
```

Тесты `tests/feed-filters.test.mjs` проверяют пересечение фильтров, совместимость
ссылок, валидацию URL, сброс, параметры API и сохранение контекста при переходе
в разбор. Бэкенд проверяет выбор значимости до `limit` в `tests/test_api_feed.py`.

Для ручной проверки откройте `/feed`, совместите тип и значимость с режимом
«Только риски», затем смените период. Обновите страницу, откройте карточку и
вернитесь ссылкой «Новости для бизнеса». Проверьте сброс и узкий экран.
Браузерные проверки с подменённым API не расходуют бюджет LLM.
