# Синтетические выгрузки

Задача A2-08. Два файла в формате выгрузок кейса (те же столбцы, разделитель `;`, UTF-8 с BOM), полностью придуманные. Через них сквозной сценарий проходится без настоящих данных: загрузка, профиль компании, а дальше лента и выводы.

| Файл | Строк | Что внутри |
| --- | --- | --- |
| `df_Uid_data_hack.csv` | 74 | 3 демо-компании, их окружение, по 12 компаний той же отрасли, строки с мусором |
| `df_Fid_Uid_link_hack.csv` | 24 | связанные физлица и **платежи**: в выданном файле связей их нет, здесь они есть, чтобы был виден граф контрагентов |

```
# в Docker
docker compose run --rm api python -m app.data --samples

# локально
cd backend
uv run python -m app.data --companies ../data/samples/df_Uid_data_hack.csv --links ../data/samples/df_Fid_Uid_link_hack.csv
```

Файлы собирает `backend/scripts/make_samples.py` с фиксированным зерном генератора и руками не правятся. Тест `tests/test_samples.py` падает, если файлы разошлись со скриптом, и проходит сквозной сценарий на временном PostgreSQL.

## Демо-компании

| Компания | Кто это | На чём показывать |
| --- | --- | --- |
| `U_900001` | оптовик продуктами питания, Москва, 18,2 млрд ₽, кредит и лизинг, ВЭД с Китаем и Турцией | группа из 4 компаний (склад, грузоперевозки, розница); покупатели — рестораны и сети (55% оборота у одного ресторана), поставщики — рыбопереработка, перевозчик и лизинговая компания; через общее физлицо связан с арендодателем |
| `U_900002` | производитель медтехники, Екатеринбург, 3,1 млрд ₽, гарантии и депозит, иностранный капитал, ВЭД с ОАЭ и Китаем | 70% выручки от одной региональной больницы; ставка — и риск, и возможность |
| `U_900003` | разработчик ПО, Магнитогорск, 1,3 млрд ₽, лизинг и гарантии, ВЭД с Узбекистаном | главный покупатель — металлургический комбинат: новости металлургии важны IT-компании |

Три отрасли, три региона и три разных набора чувствительности, поэтому лента у них должна заметно отличаться.

## Строки с мусором

Каждая проверяет одно правило очистки из [docs/data.md](../../docs/data.md). Профиль по ним отдаётся без ошибки.

| Компания | Что сломано |
| --- | --- |
| `U_900401` | пустые поля: форма собственности, стадия (`nan`), регион, город (`—`), численность, тип клиента, выручка |
| `U_900402` | нераспознанный флаг кредита (`возможно`), `FTS_FLAG = н/д` |
| `U_900403` | отрицательная выручка |
| `U_900404` | нулевая выручка |
| `U_900405` | выручка `1 234 567 890,50` |
| `U_900406` | несуществующий класс ОКВЭД `34.10`, отрасль угадывается по названию |
| `U_900407` | пустой код ОКВЭД, отрасль по названию |
| `U_900408` | битый код `abc` и пустое название: отрасль не определена |
| `U_900409` | код через запятую `41,20` |
| `U_900410` | тип клиента вне справочника |
| `U_900411` | страны ФТС при `FTS_FLAG = 0` |
| `U_900412` | недружественная страна и страна с риском платежей |
| `U_900413` | потенциальный клиент без продуктов |
| `U_900414` | выручка 30 млрд при штате меньше 15 человек |
| `U_900415` | численность по ФНС и СПАРК расходится |
| `U_900416` | неразрывные пробелы и кавычки в городе и регионе |
| `U_900417` | флаги словами (`да`, `Нет`) |
| `U_900420` | выручка `1000.0` — заглушка выгрузки: выручка неизвестна, размера и признака «крупный бизнес» нет |
| `U_900418` | строка короче заголовка |
| `U_900419` | строка длиннее заголовка: отбрасывается, профиля нет |
| `U_900001` второй раз | дубликат с пустыми полями: остаётся полная строка |

В файле связей: повтор физлица, физлицо без компании, платёж самому себе, платёж без суммы, нулевой платёж к уже существующей паре.
